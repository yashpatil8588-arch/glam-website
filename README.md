## 🔧 Customization Notes

### To Add Photos/Images:
Replace the `.image-placeholder` divs in `about.html` with actual images:
```html
<img src="images/your-photo.jpg" alt="Description" style="width: 100%; border-radius: 10px;">
```

### To Update Brand Colors:
Modify CSS variables in `styles.css` (lines 12-26):
```css
--primary-color: #0a0e27;
--gold-accent: #c9a961;
```

### To Add New Brands:
Add brand cards in `brands.html` following this structure:
```html
<div class="brand-card">
    <div class="brand-name">BRAND NAME</div>
    <div class="brand-category">Category | Subcategory</div>
</div>
```
